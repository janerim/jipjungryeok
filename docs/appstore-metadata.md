# App Store 등록 문구

App Store Connect 에 그대로 붙여 넣는 텍스트다. 여기서 관리하는 이유는, 스토어에서
직접 고치면 무엇을 왜 바꿨는지 남지 않기 때문이다. 고칠 때는 이 파일을 먼저 고친다.

각 항목의 글자 수 제한이 다르고 한글도 한 글자로 센다. 아래 숫자는 현재 길이다.

---

## 프로모션 텍스트 (79 / 170자)

> 빌드를 새로 올리지 않고도 언제든 바꿀 수 있는 유일한 항목이다. 이벤트나 계절 문구에 쓴다.

```
다이얼을 돌려 시간을 맞추고, 숫자를 눌러 시작합니다. 끝나면 한 줄만 남기세요.
계정도 광고도 없고, 기록은 전부 이 기기 안에만 있습니다.
```

---

## 키워드 (71 / 100자)

> 쉼표 뒤에 공백을 넣지 않는다 — 공백도 글자 수에 들어간다.
> **앱 이름(집중력)은 넣지 않는다.** 이름은 이미 검색에 색인되므로 자리 낭비다.
> `포모도로`와 `뽀모도로`를 둘 다 넣은 것은 한국어 표기가 갈리기 때문이다.

```
타이머,집중,포모도로,뽀모도로,공부,생산성,시간관리,공부타이머,딥워크,작업시간,회고,캘린더,위젯,루틴,몰입,스터디,시간기록,습관
```

## 설명 (1127 / 4000자)

> 첫 세 줄만 접히지 않고 보인다. 거기서 이 앱이 무엇인지 끝나야 한다.

```
집중력은 원형 다이얼을 돌려 시간을 맞추는 미니멀 타이머입니다.

화면에는 다이얼과 숫자뿐입니다. 시작 버튼도, 설정할 것도, 광고도 없습니다.


■ 돌리고, 누르고, 잊으세요

다이얼을 손가락으로 돌리면 1분 단위로 시간이 잡힙니다. 최대 90분.
숫자를 누르면 시작하고, 다시 누르면 멈춥니다. 길게 누르면 세션이 끝납니다.

시간 계산은 절대시각 기준입니다. 앱을 완전히 종료했다가 다시 켜도, 화면을 꺼둔
채로 몇 시간이 지나도 남은 시간이 정확합니다.


■ 완료는 조용히

세션이 끝나도 소리가 나지 않습니다. 진동도 없습니다.
앱을 보고 있었다면 화면이 이미 말해 주고, 다른 일을 하고 있었다면 무음 배너가
조용히 뜹니다. 집중이 끝난 순간에 요란할 이유가 없습니다.


■ 한 줄 회고

세션이 끝나면 무엇을 했는지 한 줄 물어봅니다. 건너뛰어도 됩니다.
남긴 메모는 기록 화면에서 날짜별로 다시 읽을 수 있고, 캘린더 일정에도 함께
들어갑니다. 부담스러우면 설정에서 끌 수 있습니다.


■ 캘린더에 남기기

완료한 세션을 캘린더에 자동으로 기록합니다. 어느 캘린더에 남길지 직접 고를 수
있습니다. 캘린더 기록을 꺼도 이미 만들어진 일정은 지우지 않습니다.


■ 오늘과 이번 주

통계는 두 가지만 봅니다. 오늘 얼마나 했는지, 이번 주에 며칠 나왔는지.
숫자를 여러 개 늘어놓는 대신 링 하나와 요일 일곱 칸으로 보여줍니다.
그 아래에는 지난 세션과 메모가 날짜별로 쌓입니다.


■ 위젯과 실시간 현황

홈 화면 위젯으로 오늘 집중 시간과 이번 주를 봅니다.
잠금화면 위젯도 있습니다.
세션이 도는 동안에는 잠금화면과 Dynamic Island에 남은 시간이 표시되고,
앱을 닫아 두어도 정확하게 줄어듭니다.


■ 세 가지 색

종이, 세이지, 모노 중에서 고릅니다.
밝은 모드와 어두운 모드는 기기 설정을 그대로 따릅니다.


■ 수집하지 않습니다

계정이 없습니다. 로그인도, 서버도, 분석 도구도, 광고도 없습니다.
집중 기록과 메모는 전부 이 기기 안에만 저장되며 어디로도 전송되지 않습니다.
앱을 지우면 함께 사라지고, 설정에서 언제든 전부 지울 수 있습니다.


포모도로처럼 쉬는 시간을 강제하지 않고, 목표를 세우라고 하지도 않습니다.
그냥 시간을 맞추고 집중하면 됩니다.
```

## 심사 메모

> 캘린더 **전체 접근**을 요청하는 앱은 심사에서 사유를 묻는다. 미리 적어 둔다.

```
캘린더 전체 접근 권한은 사용자가 기록할 캘린더를 직접 고를 수 있도록 캘린더
목록을 읽기 위해서만 사용합니다. 일정 내용을 읽거나 저장하거나 외부로 전송하지
않습니다.

이 권한은 설정 화면에서 사용자가 "캘린더 선택 허용" 을 누른 경우에만 요청하며,
기본 동작은 쓰기 전용 권한(NSCalendarsWriteOnlyAccessUsageDescription)입니다.
쓰기 전용 권한으로는 EKEventStore.calendars(for:) 가 캘린더 목록을 반환하지 않아
사용자가 기록 대상을 선택할 수 없기 때문입니다.

앱은 서버가 없으며 어떤 데이터도 수집하거나 전송하지 않습니다.
```
