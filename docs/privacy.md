# 개인정보 처리방침 — 집중력

**시행일: 2026년 8월 22일**

집중력(Jipjungryeok)은 원형 다이얼로 시간을 맞추고 집중하는 타이머 앱입니다.
이 앱은 **어떤 개인정보도 수집하지 않고, 어디로도 전송하지 않습니다.**

## 수집하는 정보

없습니다.

이 앱에는 서버가 없습니다. 회원가입도, 로그인도, 계정도 없습니다.
분석 도구나 광고 SDK를 넣지 않았고, 제3자 서비스와 통신하지 않습니다.

## 기기에 저장되는 것

앱이 동작하려면 아래 정보를 **사용자의 기기 안에만** 저장합니다.
개발자를 포함해 누구도 이 정보에 접근할 수 없습니다.

| 저장 항목 | 내용 |
|---|---|
| 집중 세션 기록 | 시작·종료 시각, 집중한 시간, 완료 여부 |
| 세션 메모 | 세션이 끝난 뒤 사용자가 직접 입력한 한 줄 메모 |
| 앱 설정 | 기본 시간, 색 테마, 캘린더 기록 사용 여부, 선택한 캘린더 |

앱을 삭제하면 이 정보는 기기에서 함께 삭제됩니다.
앱 안의 **설정 → 데이터 초기화** 로도 언제든 전부 지울 수 있습니다.

## 기기 권한

앱은 아래 권한을 사용자가 허용한 경우에만 사용합니다. 언제든 iOS 설정에서 취소할 수 있습니다.

### 캘린더

- **쓰기 전용 권한** — 완료한 집중 세션을 사용자의 캘린더에 일정으로 남깁니다.
  설정에서 "캘린더 기록" 을 켤 때만 요청합니다.
- **전체 접근 권한** — 기록할 캘린더를 사용자가 **직접 고를 수 있도록** 캘린더 목록을 읽습니다.
  설정에서 "캘린더 선택 허용" 을 누른 경우에만 요청합니다.
  캘린더의 **일정 내용을 읽거나, 저장하거나, 외부로 보내지 않습니다.**
  쓰기 전용 권한으로는 캘린더 목록을 가져올 수 없어 이 권한이 필요합니다.

캘린더 기록을 끄더라도 이미 만들어진 일정은 지우지 않습니다. 사용자의 캘린더이기 때문입니다.

### 알림

세션이 끝났을 때 알리기 위해 로컬 알림을 사용합니다.
알림은 기기 안에서 예약되며 서버를 거치지 않습니다. 소리 없이 배너만 표시합니다.
