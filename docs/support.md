# 집중력 — 지원

원형 다이얼을 돌려 시간을 맞추고 집중하는 미니멀 타이머입니다.

## 쓰는 법

**시간 맞추기** — 다이얼을 손가락으로 돌립니다. 1분 단위로 걸리고, 최대 90분입니다.
자주 쓰는 시간은 설정의 "기본 시간" 에 정해 두면 앱을 열 때마다 그 값에서 시작합니다.

**시작과 정지** — 아래 큰 숫자를 누르면 시작합니다. 다시 누르면 일시정지, 한 번 더
누르면 이어서 갑니다. 다이얼을 0.6초 길게 누르면 세션이 끝납니다.

**회고** — 세션이 끝나면 무엇을 했는지 한 줄 물어봅니다. 건너뛰려면 오른쪽 위 X 를
누르거나 시트를 아래로 내리면 됩니다. 이 창이 부담스러우면 설정에서 "회고 남기기" 를
끄면 됩니다.

**기록 보기** — 통계 화면의 "기록 › 전체" 에서 지난 세션을 날짜별로 볼 수 있습니다.

## 자주 묻는 것

**세션이 끝났는데 아무 소리도 안 나요**

의도한 동작입니다. 집중이 끝난 순간에 요란할 이유가 없다고 보고, 소리도 진동도
넣지 않았습니다. 다른 앱을 보고 있었다면 무음 배너가 조용히 뜹니다.
배너가 안 보인다면 iOS 설정 › 알림 › 집중력에서 알림이 켜져 있는지 확인해 주세요.

**앱을 껐는데 타이머가 계속 맞나요**

맞습니다. 남은 시간은 시작한 시각을 기준으로 다시 계산합니다. 앱을 완전히 종료했다가
다시 켜도, 화면을 꺼둔 채 몇 시간이 지나도 값이 어긋나지 않습니다.

**캘린더 목록이 비어 있어요**

기록할 캘린더를 고르려면 캘린더를 읽을 수 있어야 합니다. 설정에서 "캘린더 선택 허용"
을 누르면 목록이 나옵니다. 그 전까지는 기본 캘린더에 기록됩니다.
앱은 일정 내용을 읽거나 저장하지 않습니다.

**위젯이 갱신되지 않아요**

세션을 끝내면 곧 갱신됩니다. 그대로라면 위젯을 길게 눌러 제거한 뒤 다시 추가해 보세요.

**기록을 다른 기기로 옮길 수 있나요**

지금은 안 됩니다. 모든 기록이 이 기기 안에만 저장되고 서버가 없습니다.

**기록을 지우고 싶어요**

설정 › 데이터 초기화. 확인을 두 번 거칩니다. 캘린더에 이미 만들어진 일정은
사용자의 것이므로 지우지 않습니다.
